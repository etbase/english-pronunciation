現在這個版本可以做什麼？

可以輸入英文句子、播放標準美式發音、錄音，並把錄音送到 Azure Speech Pronunciation Assessment 做真實評分。系統會保存最近 10 筆練習紀錄。標準發音會優先使用 Azure 神經語音；若後端尚未設定或暫時失敗，會改用瀏覽器內建語音。

現在的發音分析是真的嗎？

是。總體發音、準確度、流暢度、朗讀完整度都來自 Azure Pronunciation Assessment 的 PronScore、AccuracyScore、FluencyScore、CompletenessScore。韻律自然度（Prosody）目前尚未啟用，畫面上不會顯示這項分數。

為什麼還沒有韻律自然度分數？

Azure 的 Prosody 是加購評分，目前先不開啟，避免額外用量。之後若要加入，可以直接顯示官方 ProsodyScore，不會另外發明重音、語調、語速或節奏的分數。
